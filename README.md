# GitHub Universe 2026 Ships — Talk Track

Static GitHub Pages talk track. Open `index.html` locally or via Pages.

## Screenshots

Each section has a `<figure class="shot">` pointing at `assets/<name>.png`; until the image exists a dashed placeholder is shown. Capture them from a machine that can reach github.blog:

```
npm i playwright && npx playwright install chromium
node scripts/capture.mjs
```

Crop/replace any image manually (same filename) if a tighter shot reads better on stage.

Items marked `*` need fact-checking against the official changelog/blog before presenting.
